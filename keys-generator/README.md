# Keys generator utility
This folder contains a command-line utility for generating a set og keys for an interchange based on a json description
of its trust chain.
To run it from a shell, you can use the command `java -jar keys-generator-<version>.jar`. To get usage help, just add
the `--help` flag to the command.

The file singlenode-keys.json is provided as an example of a simple structure of the structure for a single interchange 
with keys for a few predefined service providers.
